# SearchHub M2B：管理 UI（Vue3 前端）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 SearchHub 管理后台前端：Vue3 + TypeScript + Naive UI 单页应用（登录、仪表盘、供应商管理含 Key 池、策略与缓存、调用方 Token、历史查询、系统设置），支持中英文、明暗主题、自定义壁纸，构建产物由 FastAPI 同容器托管。

**Architecture:** 前端独立于 `frontend/` 目录（Vite 构建）。开发时 Vite dev server 代理 `/api`、`/v1`、`/healthz` 到本地后端（同源、Cookie 会话天然可用）；生产时 `npm run build` 产物 `frontend/dist` 由 FastAPI 挂载（StaticFiles + SPA fallback，`SEARCHHUB_WEB_DIST` 可覆盖路径）。状态：Pinia（auth store + ui 偏好 store，localStorage 持久化）；路由：vue-router 4 + 登录守卫；UI：Naive UI（自带暗色主题与中英文 locale）；图表：echarts 6 封装 `BaseChart.vue`。所有文案走自制轻量 i18n（zh/en 字典，`t()` 点路径查找）。

**Tech Stack:** vue ^3.5、vite ^7.3、@vitejs/plugin-vue ^6.0、typescript ~5.9、vue-tsc ^2.2、vue-router ^4.6、pinia ^3.0、naive-ui ^2.45、echarts ^6.1、vitest ^3.2 + jsdom ^26（测试）；后端集成用现有 FastAPI。

## Global Constraints

- 前端目录 `frontend/`；Node >= 20（环境为 24）；包管理器 npm
- 依赖版本锁定（package.json 使用这些版本下限）：vue ^3.5.41、vite ^7.3.6、@vitejs/plugin-vue ^6.0.8、typescript ~5.9.3、vue-tsc ^2.2.12、vue-router ^4.6.4、pinia ^3.0.4、naive-ui ^2.45.0、echarts ^6.1.0、vitest ^3.2.7、jsdom ^26
- 所有 API 调用同源（dev 走 Vite proxy → http://127.0.0.1:8000），fetch 带 `credentials: "same-origin"`；统一响应信封 `{success, data, error}`，非 success 抛错展示 error；admin API 401 → 跳转 `/login`
- 主题默认亮色、语言默认中文；localStorage 键：`sh_theme`（light|dark）、`sh_lang`（zh|en）、`sh_wallpaper`（url 或 dataURL）
- 密钥/Token 永不完整回显：新增 Token 明文只在创建弹窗显示一次（带复制按钮）；Key 只显示掩码
- 所有界面文案必须有 zh 与 en 两套；naive-ui locale 随语言切换
- 构建验证：`npm run build`（vue-tsc 类型检查 + vite build）必须通过；vitest 单测通过
- 后端静态托管：`SEARCHHUB_WEB_DIST` 环境变量指定 dist 目录（默认 `<repo>/frontend/dist`）；SPA fallback 只对非 API 路径生效；API 路径 404 返回 JSON 错误形状
- 提交风格：`feat:`/`fix:`/`chore:`；后端改动（Task 8）仍走 pytest 全量回归

`frontend/src/api/client.ts`:
```ts
export class ApiError extends Error {
  constructor(
    public status: number,
    message: string,
  ) {
    super(message)
    this.name = 'ApiError'
  }
}

export let onUnauthorized: () => void = () => {
  window.location.href = '/login'
}

export async function request<T>(
  path: string,
  options: { method?: string; body?: unknown; params?: Record<string, string | number | undefined> } = {},
): Promise<T> {
  const { method = 'GET', body, params } = options
  let url = path
  if (params) {
    const qs = new URLSearchParams()
    for (const [k, v] of Object.entries(params)) {
      if (v !== undefined && v !== '') qs.set(k, String(v))
    }
    const s = qs.toString()
    if (s) url += `?${s}`
  }
  const init: RequestInit = { method, credentials: 'same-origin' }
  if (body !== undefined) {
    init.headers = { 'Content-Type': 'application/json' }
    init.body = JSON.stringify(body)
  }
  const resp = await fetch(url, init)
  let payload: { success: boolean; data?: T; error?: string } | null = null
  try {
    payload = (await resp.json()) as typeof payload
  } catch {
    payload = null
  }
  if (resp.status === 401) {
    onUnauthorized()
  }
  if (!resp.ok) {
    throw new ApiError(resp.status, payload?.error ?? `HTTP ${resp.status}`)
  }
  if (!payload || payload.success === false) {
    throw new ApiError(resp.status, payload?.error ?? 'request failed')
  }
  return payload.data as T
}
```
